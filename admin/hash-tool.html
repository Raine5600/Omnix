Make the admin password hash

This page does not send your password anywhere. It does not make any network request. The hash is calculated in this browser. Copy the line into the Cloudflare secret named ADMIN_PASSWORD_HASH. Do not put the password or the hash in git, email, or a pull request.

The free Pages plan only allows a very short burst of computing on sign-in. 20000 iterations is the one that fits. The number is stored inside the hash, so sign-in uses the same count you pick here.
